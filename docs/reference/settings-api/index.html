Settings API

Wireframe\Settings is the primary API for reading and writing saved field values from anywhere in your plugin. Every call takes your plugin’s option_key as the first argument, so multiple plugins sharing the framework can never collide on storage.

Section titled “Reading”

Type-safe getters

Section titled “Type-safe getters”
MethodAlways returns
Settings::bool($opt, $key, $default = false)bool
Settings::int($opt, $key, $default = 0)int
Settings::float($opt, $key, $default = 0.0)float
Settings::string($opt, $key, $default = '')string
Settings::array($opt, $key, $default = [])array
Settings::json($opt, $key, $default = null)decoded JSON

Coercion is best-effort: string '1' becomes bool true, string '3.14' becomes float 3.14, etc. Use these in business code so you don’t have to defensively cast at every call site.

Writing

Section titled “Writing”
MethodNotes
set($opt, $key, $value)Replace the value at $key.
toggle($opt, $key)Flip a boolean.
increment($opt, $key, $by = 1)Bump a numeric value.
decrement($opt, $key, $by = 1)Drop a numeric value.
push($opt, $key, $value)Append to an array value.
forget($opt, $key)Remove a key entirely.

Caution

Writes via Settings:: bypass the framework’s validation and access pipeline — they go straight to update_option(). Use them for internal bookkeeping (counters, cached flags) rather than for accepting user input. For user input use the REST save endpoint.
